# 产品需求规格与系统边界

本文档定义个人自定义工作台的产品交互目标、全局默认底座能力、12 大业务域功能全景以及系统明确排除的职责边界，作为宿主与页面双端共同遵循的顶层需求基线。

---

## 一、核心使用流与协同模式

1. **独立桌面窗口运行**：工作台脱离 AI Agent 聊天侧栏与常规浏览器标签页，以独立桌面窗口启动、驻留任务栏及参与系统窗口切换，首启即支持完全离线运行。
2. **本机 Agent 驱动定制**：客户通过本机编码 Agent 直接读取、修改本地工作台目录中的前端源码与配置文件，经本地前端构建与窗口刷新即可即时预览，全程无需启动常驻业务后台服务或安装桌面端原生编译环境。
3. **代码与数据生命周期解耦**：界面源码、配置与用户业务数据（结构化记录、图片附件）分离存储。Agent 重构布局、替换视图或重置模板时，底层历史业务数据完整保留。

## 二、全局底座默认能力

以下能力作为工作台默认基础设施提供，无需用户在定制具体模块时单独声明：

| 底座维度 | 规格要求 |
| :--- | :--- |
| **同源多视图切换** | 同一份底层数据集支持在列表、卡片、看板、日历、四象限、自定义表格等视图间无缝切换；任一视图发生状态变更（如勾选完成），其余关联视图同步更新。 |
| **检索、筛选与排序** | 内置标签体系、多条件组合筛选、字段排序，以及跨所有已启用模块的关键词全局搜索。 |
| **视觉与响应式适配** | 支持深色/浅色主题切换；界面随窗口宽度自适应重排，兼容窄窗侧栏单列紧凑排布与宽面板侧栏导航加多列网格布局。 |
| **存储状态显式表征** | 状态指示器严格区分“已保存到本机”与“跨设备已同步”（无同步后端时仅表征本机落盘状态，避免误导用户认为已云端备份）。 |
| **备份恢复与防误删** | 支持带 Schema 版本号的 JSON 导入导出与含本地图片的完整备份包迁移；支持 CSV 导出与打印友好排版；清空或批量销毁数据强制二次确认。 |
| **开箱示例数据** | 首次初始化预置 3~5 条结构完整的示例记录（必须包含至少 1 条逾期状态条目），直观呈现置顶聚焦与标红提醒效果。 |
| **本地图片附件规范** | 单条记录最多关联 9 张图片，写入前自动等比压缩至长边不超过 800px，二进制文件持久化于本机受管资产目录。 |

## 三、业务功能域需求全景

系统面向个人效率与生活管理提供 12 大可选业务域（共 68 项标准场景规格），供用户或本机 Agent 按需裁剪、组合与扩展：

### 1. 任务与待办
- **今日聚焦区**：页面顶部置顶，自动聚合“已逾期、今日到期、3 天内到期”条目；逾期项标红警示，单条支持一键完成与一键顺延。
- **多清单待办**：支持多清单分组、P0/P1/P2 优先级、多标签、截止日期及备注。
- **四象限矩阵**：按“重要 × 紧急”二维分区展示并支持跨象限拖拽变更属性。
- **重复任务**：支持按天、周、月或每 N 天配置周期规则，当前实例完成后自动推算并生成下一周期任务。
- **子任务拆解**：单任务拆分为多步骤并计算进度条，全部子步骤勾选后自动将主任务置为完成。
- **收集箱（Inbox）**：支持单句快速录入暂存，延后归类整理。
- **完成归档**：已完成条目按周、月自动聚合归档，支持撤销完成态并恢复至活跃待办。
- **顺延统计**：累计单条任务被推迟的次数，单独提取并高亮反复顺延的滞留任务。

### 2. 时间管理
- **日历视图**：提供月视图与周视图，叠加渲染待办任务与日程事件，点选日期穿透查看当日明细。
- **时间块排程（Time Blocking）**：将单日切分为连续时间段，按段填入待执行事项。
- **倒计时与纪念日**：支持配置多个目标日期，分别计算剩余倒计时天数或事件已发生天数。
- **番茄钟与计时器**：支持正计时与倒计时模式，自动累加专注时长并提供历史回看。
- **时间账本**：记录事项起止时间戳，按分类自动汇总工时消耗。
- **周排期表**：横向 7 天 × 纵向条目的二维排期网格，承载周期性固定节奏安排。

### 3. 打卡与日常记录
- **习惯打卡矩阵**：多习惯 × 日历网格视图，实时计算当前连续天数与历史最长连续纪录。
- **年度热力图**：365 格色阶深浅映射全年每日完成强度与坚持度。
- **计数器型目标**：设定每日目标频次（如饮水杯数、运动组数），配套当日完成进度条。
- **数值趋势记录**：每日录入单一量化指标（体重、分数、粉丝数、收入等），自动绘制变化折线。
- **标签型日志**：每日勾选离散状态标签（如高效、疲惫、被打断），按周期统计频次分布。
- **连续与断卡记录**：显式记录断卡发生日期与归因备注，保留真实行为轨迹。

### 4. 内容与知识
- **速记与笔记**：支持纯文本或轻量富文本录入、标签归类及按日期归档。
- **素材灵感库**：结构化记录标题、链接、来源、分类、评分与备注，支持一键复制源链接。
- **卡片墙**：以瀑布流或网格卡片浏览金句、短片段与话术。
- **模板库**：沉淀常用文案、回复话术与代码片段，支持点击即复制到系统剪贴板。
- **图片附件与全局搜索**：复用全局底座的 800px 9 图本地附件能力与跨模块关键词检索能力。

### 5. 数据与统计
- **指标卡**：并排展示 3~6 个核心量化数字及环比升降箭头。
- **统计图表组**：包含趋势**折线图**、横向对比**柱状图**、占比分布**饼图/环形图**及目标达成**进度环**。
- **自定义表格**：支持用户自定义字段结构，具备列排序、条件筛选与单元格行内编辑能力。
- **排行榜**：支持指定任意数值或评分字段生成 Top N 排序列表。

### 6. 财务与账目
- **收支记账**：记录金额、分类、账户、备注与日期；默认人民币符号（`¥`），视觉区分支出标红、收入标绿。
- **预算进度**：月度总预算对比累计已花费，实时推算剩余可用额度与月末前日均可用金额。
- **分类统计**：生成各消费/收入分类占比饼图，支持跨月度结构变化对比。
- **周期账单**：登记房租、订阅服务等固定周期支出，临近到期提醒并支持一键转化为实际账单。
- **借还台账**：管理应收（谁欠我）与应付（我欠谁）对象、金额及结清状态。
- **储蓄目标**：设定目标金额，展示当前储蓄进度环并根据历史存入速率估算达成日期。

### 7. 身体与健康
- **体重体脂**：每日数值记录，叠加渲染实际趋势折线与目标基准线。
- **运动打卡**：记录运动类型、时长、强度与备注，按周汇总运动总量。
- **饮水与饮食**：按餐次明细或饮水杯数快捷记录。
- **睡眠记录**：录入入睡与起床时间，自动换算单次睡眠时长与周期均值。
- **用药与补剂清单**：每日服药/补剂勾选确认，支持周期性待办提醒。

### 8. 清单、库存与资产
- **物品库存**：维护名称、当前数量、存放位置及补货阈值，库存低于阈值自动标红预警。
- **购物与愿望清单**：记录预估价格、商品链接与购买优先级，支持勾选转化为已购状态。
- **到期台账**：统一跟踪会员、域名、设备保修、证件有效期，临近失效自动置顶提醒。
- **收藏集**：覆盖书、影、音、游戏、店铺等条目，维护“想看/在看/看完”状态流转与个人评分。
- **步骤卡（SOP）**：将烹饪、运维等标准操作流程拆解为有序步骤，支持执行时逐项勾选。
- **检查清单模板**：固化出行前、发版前、交付前等核查项模板，支持按次实例化核对。

### 9. 项目与流程
- **看板视图**：支持自定义流转列（如灵感 → 进行中 → 已完成）及卡片跨列拖拽。
- **里程碑**：将长周期目标拆解为有序阶段，独立核算各阶段完成度。
- **简化时间轴（Timeline）**：以起止日期横条渲染任务排期，直观暴露时间重叠与排期空档。
- **周期回顾**：按迭代周期结构化沉淀“已完成事项、当前卡点、下期改进项”。

### 10. 人与关系
- **联系人轻档**：记录姓名、关系分类、生日、最近联系日期与备注，生日前夕自动置顶提醒。
- **互动记录**：按时间轴用简短语句记录每次沟通纪要，支持随时回溯上次沟通上下文。

### 11. 效率小工具
- **自定义快捷表单**：由用户自由定义字段组合，面向高频结构化数据的逐条连贯录入。
- **公式计算器**：支持自定义运算公式（如单价折算、时薪核算、分期还款、阶梯提成）。
- **随机抽取**：自定义候选池，用于抽签、抽题或抽人决策。
- **多维评分器**：设定多个评估维度与各自权重，录入单项打分后自动计算加权总分并排序。
- **每日三问**：固定 3 个核心反思问题每日打卡作答，支持跨时间纵向对比变化。
- **决策记录**：事前登记备选方案、决策依据与预期结果，事后回溯复盘判断准确度。

### 12. 复盘与输出
- **日记与每日一句**：按日期归档短句或长文日记，支持按日历与历史流翻阅。
- **周复盘**：自动拉取并填入本周已完成项与未完成遗留项，用户仅需补充“本周卡点”与“下周计划”。
- **情绪与状态曲线**：每日 1~5 分量化评分结合状态标签，生成长期情绪波动曲线。
- **一键汇总成文本**：勾选多条记录后按预设模板拼接为标准日报/周报纯文本，一键复制输出。
- **导出与打印**：承接底座的 JSON 备份、CSV 表格导出及打印专用精简排版。
- **只读分享快照**：受限于纯本地数据库无公网直连能力，分享场景通过导出自包含的静态数据快照供他人只读浏览（不包含任何编辑入口）。

## 四、系统边界与明确不做项

为保障架构轻量性与单机可靠性，以下事项明确划出本系统职责范围之外：

1. **不自动抓取第三方封闭平台私有数据**：不内置针对抖音后台、银行流水、微信聊天等无开放授权平台的爬虫或逆向采集器；此类数据仅通过手动录入、剪贴板粘贴或 CSV/JSON 导入接入（注：用户主动拥有合法接口与密钥的开放 HTTP API，可通过宿主原生网络代理合规调用）。
2. **不做账号体系与云端同步后台**：面向单用户本机独立使用，不建设注册登录、多租户鉴权或云端业务数据库；跨设备迁移依赖带版本号的备份包导入导出。
3. **首版不做操作系统级后台常驻推送**：不依赖系统通知中心定时弹窗，所有逾期、今日待办、临近到期及生日提醒统一通过“打开窗口即见”的顶部置顶聚焦区触达。
4. **不存储视频与大体积二进制文件**：资产引擎仅面向压缩后图片等轻量附件，禁止作为本地视频库或大文件网盘使用。
5. **运行时页面零外部 CDN 链接**：所有 UI 组件、图标、字体、日历与图表引擎必须在构建期打包至本地静态产物中，严禁运行时请求外部公共 CDN，确保完全断网环境下界面与功能零降级（注：零外链指构建产物自包含，而非排斥在工程中引入成熟开源库）。
6. **不做无托管条件下的实时动态链接分享**：他人设备无法直接访问用户本机 SQLite 数据库；若需持续实时更新的在线分享视图，须另行引入外部静态/数据托管服务，不属于本单机系统默认范畴。
