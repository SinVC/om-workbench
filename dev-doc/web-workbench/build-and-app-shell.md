# Vite 构建管线与自适应应用壳层

> **共享规则引用**：遵循 [产品需求规格与系统边界](../shared/product-requirements-and-boundaries.md) 的深浅色、响应式、状态表征与零外链要求，以及 [技术栈选型与关键架构决策](../shared/tech-stack-and-decisions.md) 的 React + TypeScript + Vite 统一主路径决策。

---

## 一、职责边界

本模块提供页面内置窗口操作区和共享外壳；背景、窗口轮廓、滚动区域与滚动条遵循随前端交付的[工作台内容布局规范](../../web-workbench/docs/content-layout.md)。窗口按钮通过共享 IPC 契约执行，拖动区域使用 Tauri 原生机制。

- **本模块负责**：
  - 提供配套的 Vite 前端构建与监听管线，将客户工作台目录中的 React（TSX）源码、样式、图标与第三方依赖统一打包为离线自包含的静态 HTML / CSS / JS 产物，并在构建完成后触发宿主窗口刷新。
  - 实现工作台顶层 **应用壳层（App Shell）**：承载全局导航框架（宽窗侧栏导航 / 窄窗紧凑顶栏或抽屉切换）、跨模块全局搜索入口、备份导入导出入口及清空数据二次确认拦截弹窗。
  - 维护基于 CSS 自定义属性（Design Tokens）的 **深色 / 浅色主题引擎**，统一管控全局配色、字体、圆角、间距与信息密度变量。
  - 建立基于 CSS 响应式网格与 **容器查询（`@container`）** 的双形态布局骨架，驱动页面在窄长侧栏（单列纵向流）与宽幅面板（多列并排看板）之间平滑重排。
  - 渲染全局存储状态指示器，如实反馈本机落盘状态（明确区分“已保存到本机”与跨设备同步概念）。
- **本模块不负责**：
  - 操作系统级桌面窗口尺寸调整、屏幕贴边与坐标记忆（归属宿主 [外置工作区挂载与多形态窗口管理](../tauri-host/window-and-workspace.md)）。
  - 跨端 IPC 调用封装及具体模块的领域规则计算（归属 [前端 SDK、领域规则引擎与跨视图状态同步](sdk-and-domain-services.md)）。
  - 日历、表格、图表等具体业务视图的内部交互渲染（归属 [多视图投影引擎与开源交互组件底座](ui-primitives-and-views.md)）。

## 二、架构关系

- **跨顶层域产出对接**：Vite 管线输出的离线静态产物直接写入受管工作台构建目录，供宿主 [外置工作区挂载与多形态窗口管理](../tauri-host/window-and-workspace.md) 通过自定义资源协议加载渲染。
- **域内底座支撑**：向下游 [多视图投影引擎与开源交互组件底座](ui-primitives-and-views.md) 及 [面向 Agent 的源码示例、工作台模板与业务模块组装](templates-and-modules.md) 提供语义主题变量、命名查询容器（Named Query Containers）及壳层挂载插槽；订阅 [前端 SDK、领域规则引擎与跨视图状态同步](sdk-and-domain-services.md) 暴露的全局持久化状态与全局检索结果。

## 三、接口契约

| 契约维度 | 暴露能力 | 约束规范 |
| :--- | :--- | :--- |
| **构建与热更管线** | 单次全量构建 / 增量监听构建并刷新 | 构建产物必须使用兼容宿主自定义资源协议的相对路径；打包产物中严禁出现指向外部 CDN 的字体、图标或脚本引用；源码语法错误时在构建终端输出清晰定位，且不覆盖上一版可用产物导致宿主白屏。 |
| **主题令牌契约** | 深浅色切换与全局视觉变量 | 暴露语义化背景色、文本层级色、状态警示色（如逾期红、收入绿）、间距及圆角令牌；业务组件仅消费语义变量而非硬编码色值，保障换肤与深浅色一键生效。 |
| **自适应布局容器** | 分栏骨架与 `@container` 尺寸上下文 | 为主内容区及各分栏面板声明独立的 CSS 容器查询上下文，使嵌入其中的任意组件能够依据**自身所在容器的实时可用宽度**而非浏览器总视口宽度切换紧凑/舒展形态。 |
| **壳层全局服务** | 全局搜索面板 / 本机保存状态栏 / 破坏性操作确认框 | 全局搜索支持跨所有已注册集合检索并定位跳转；清空或覆盖恢复工作区数据前必须弹出显式二次确认框，未经确认严禁向宿主发起销毁指令。 |

## 四、关键决策

1. **自动化构建管线消解 JSX 编译门槛**：React 源码无法由 WebView 直接裸跑，因此随产品交付预配置好的 Vite 增量构建与监听工具。本机 Agent 修改 TSX 或样式文件后自动触发编译并联动 Tauri 窗口刷新，在保留 TypeScript 类型检查与组件生态优势的同时，维持近似改纯 HTML 的顺滑体验。
2. **容器查询优先于全局媒体查询**：在宽面板模式下，同一组件既可能独占全宽，也可能被排布在三分之一宽度的窄分栏中。采用 CSS 容器查询可确保组件无论被放置在侧栏窗口还是宽面板的窄列中，均能准确触发紧凑降级排版。
3. **本机保存状态零歧义呈现**：针对本地优先且无云端后台的产品边界，壳层状态指示器严格限定表述为“保存中 / 已保存到本机 / 本地保存失败”，彻底摒弃“已同步”等易引发跨设备云备份误解的措辞。

---

## 五、验收口径

1. **断网零外链校验**：在完全断网环境下启动构建产物并切换深浅色主题、浏览图标与字体，网络面板无任何外部域名请求或资源加载报错。
2. **Agent 改码热更闭环**：修改任意页面组件的文本或布局样式后，配套监听管线自动完成增量构建并驱动独立桌面窗口刷新展示新界面，构建失败时旧窗口保持可用不白屏。
3. **布局与窗口外观**：按[工作台内容布局规范的回归矩阵](../../web-workbench/docs/content-layout.md#四外观回归与问题定位)验证滚动、背景和圆角，并将窗口从窄侧栏连续拉宽至多列面板，确认重排正常、文字不重叠、普通内容不造成整窗横向溢出。
