# 多视图投影引擎与开源交互组件底座

> **共享规则引用**：遵循 [产品需求规格与系统边界](../shared/product-requirements-and-boundaries.md) 的多视图切换、图片附件规格与导出分享要求，以及 [技术栈选型与关键架构决策](../shared/tech-stack-and-decisions.md) 的开源组件选型与许可证约束。

---

## 一、职责边界

- **本模块负责**：
  - 维护以项目源码形态交付的基础交互原语（基于 `shadcn/ui` 的按钮、表单、弹窗、选择器、日期拾取器），统一接入全局主题语义变量。
  - 封装高复杂度开源交互引擎的工作台适配层：
    - **无头表格适配（TanStack Table）**：补齐统一表格视觉外观，提供列排序、多条件筛选、分页及单元格**行内编辑**交互。
    - **日历排程适配（FullCalendar MIT 标准版）**：承接月、周、日视图渲染、任务与事件叠加展示、拖拽改期及点击日期查看当日明细，并实现窄容器下的列表态降级。
    - **统计可视化底座（Recharts + 轻量内联 SVG）**：适配主题配色的折线图、横向柱状图、饼图/环形图，以及轻量内联 SVG 实现的进度环、指标环比卡与 365 格年度热力图。
  - 提供通用的 **多视图切换控制器**（支持同一数据集在列表、卡片、自定义列拖拽看板、重要×紧急四象限、日历、自定义表格间切换）以及复用的 **标签 + 筛选 + 排序工具条**。
  - 提供前端媒体预处理与导出排版工具：上传图片自动等比压缩至长边 ≤ 800px 并校验单条最多 9 张上限；支持选中条目按模板拼接纯文本一键复制、CSV 格式化导出、打印专用排版（`@media print`）及无编辑入口的静态只读快照生成。
- **本模块不负责**：
  - 重复任务推算、预算核算等纯业务规则及底层 IPC 通信（归属 [前端 SDK、领域规则引擎与跨视图状态同步](sdk-and-domain-services.md)）。
  - 全局窗口双形态外框与 Vite 打包流程（归属 [Vite 构建管线与自适应应用壳层](build-and-app-shell.md)）。
  - 面向具体业务场景组装的完整示例模块与预设工作台（归属 [面向 Agent 的源码示例、工作台模板与业务模块组装](templates-and-modules.md)）。

## 二、架构关系

- **依赖上游底座**：消费 [Vite 构建管线与自适应应用壳层](build-and-app-shell.md) 提供的语义主题令牌与 `@container` 容器尺寸上下文；通过 [前端 SDK、领域规则引擎与跨视图状态同步](sdk-and-domain-services.md) 获取业务集合数据、提交拖拽/行内编辑变更并上传压缩后图片字节流。
- **支撑上层组装**：作为可选积木库供首发参考示例、预设工作台模板以及客户本机 Agent 定制特殊控件（如多维评分器、简化时间轴）按需引用或直接改写源码。

## 三、接口契约

| 组件/工具分类 | 输入契约 | 输出与交互约束 |
| :--- | :--- | :--- |
| **多视图投影器与筛选栏** | 数据记录列表、字段映射描述、当前激活视图标识、筛选排序条件 | 切换视图仅改变渲染投影，不复制或隔离底层状态；拖拽与行内编辑统一委托 SDK 写入。四象限未显式选择时按优先级与截止日期推导；跨区拖拽保存显式象限并更新对应优先级，保留截止日期，不隐式改期。 |
| **开源交互适配层** | 标准化日程/统计/表格配置与数据源 | 保持薄封装，不屏蔽底层开源库原生扩展属性；FullCalendar 严格限定在 MIT 许可能力范围内运行；所有图表与日历自动响应深浅色切换。 |
| **前端图片预处理器** | 用户选取的原始图片文件集合及当前记录已关联数量 | 合计超过 9 张时直接拦截提示；对超尺寸图片在前端完成 ≤ 800px 等比缩放编码后再移交 `workbench.assets` 落盘。 |
| **格式化输出与快照器** | 选定记录集合、日报/周报文本模板或导出目标格式 | 支持一键写入剪贴板、下载标准 UTF-8 CSV、触发隐藏导航栏的干净打印视图，以及打包剥离所有增删改控件的静态只读 HTML 快照。 |

## 四、关键决策

1. **源码白盒化与复杂度分级选型**：基础控件采用源码直接落入工程目录的 `shadcn/ui`，Agent 可直接查看和微调结构；仅在手写成本极高且易出缺陷的日历、数据表格、多轴图表上引入开源库，进度环、热力图等轻量图形优先采用简洁直观的内联 SVG，兼顾工程稳定度与 Agent 可读性。
2. **复杂视图在窄容器下的语义化形态降级**：当组件所在 `@container` 宽度收缩至侧栏窄窗阈值时，月历网格与多列宽表禁止硬性挤压字体，必须自动切换为紧凑型日程摘要流或主从卡片布局。
3. **图像缩放前置在前端完成**：将 800px 图片压缩留在前端渲染层处理，既避免向 IPC 通道传输数兆原始大图，又省去宿主端引入重型原生图形处理库的跨平台编译负担。
4. **只读分享收敛为静态快照产物**：受单机本地存储物理限制，只读分享不依赖后台服务，而是将当前筛选视图及其数据固化为自包含静态快照文件供外发查阅，彻底剔除写操作入口。

---

## 五、验收口径

1. **六视图同源切换与交互落盘**：针对同一批任务记录依次切换列表、卡片、看板、四象限、日历、表格六种视图，执行看板拖拽改状态、四象限拖拽改优先级及表格行内改标题，切换至其余任意视图均即时呈现更新结果。
2. **窄窗组件优雅降级**：在侧栏窄窗口下查看日历模块，自动由多列网格切换为可读性良好的单列日程列表，无内容溢出或点击热区重叠。
3. **附件限额与多格式输出**：上传高分辨率大图后落盘图片长边严格 ≤ 800px，尝试添加第 10 张图片时准确阻断；周报文本一键复制、CSV 导出、打印预览及静态只读快照（无任何编辑按钮）均正常可用。
