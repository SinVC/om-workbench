# IPC 网关、安全权限与底层扩展

> **共享规则引用**：遵循 [技术栈选型与关键架构决策](../shared/tech-stack-and-decisions.md) 的 Tauri 2 权限模型选型，以及 [跨端通信契约与公共数据规范](../shared/ipc-contract-and-data-model.md) 中的三层接口抽象、IPC 通信机制与统一结构化错误契约。

---

## 一、职责边界

- **本模块负责**：
  - 统一收敛宿主端所有 `#[tauri::command]` 的注册挂载、参数基础合法性校验、异常捕获及结构化错误对象封装。
  - 配置启用全局 Tauri 通信桥接（`withGlobalTauri`），并封装宿主向页面主动推送状态与长任务进度的事件（Events）与流式通道（Channels）基础设施。
  - 基于 Tauri 2 `Capabilities` 机制划分窗口级最小权限边界，精确控制主工作台窗口及潜在辅助窗口可调用的命令与插件集合。
  - 实现并看护第三层 **底层受控扩展接口**（按需开放的工作区 SQL 扩展 `db` 与受限目录文件读写 `files`），在宿主侧强制落地目录沙箱、路径逃逸拦截与核心元数据表保护。
- **本模块不负责**：
  - 通用 `records`、`assets`、`config` 的常规持久化逻辑（委托 [结构化存储、本地资产与备份引擎](data-and-assets.md)）。
  - 窗口形态控制与外置页面静态协议挂载（委托 [外置工作区挂载与多形态窗口管理](window-and-workspace.md)）。
  - 外部网络请求代理与 API 凭据注入（委托 [原生网络代理与凭据托管](http-and-credentials.md)）。

---

## 二、架构关系

- **跨顶层域边界中枢**：作为 `tauri-host` 对接 `web-workbench` 的唯一 IPC 命令网关，承接 [前端 SDK、领域规则引擎与跨视图状态同步](../web-workbench/sdk-and-domain-services.md) 发起的全部跨端调用，并将宿主端事件反向投递至前端。
- **内部编排分发**：完成权限与入参预检后，将通用命令分发至窗口、存储、网络三个同级宿主子模块；针对已授权开启的第三层底层扩展请求，经沙箱校验后受控执行。

---

## 三、接口契约

| 接口分类 | 能力契约 | 安全与行为约束 |
| :--- | :--- | :--- |
| **IPC 网关基础契约** | 命令路由 / 事件推送 / 错误标准化 | 所有原生内部异常（如 I/O 错误、SQLite 锁冲突、序列化失败）在跨越 IPC 边界前统一转换为标准结构化错误码与脱敏描述，严禁向前端泄漏宿主系统敏感绝对路径或崩溃栈。 |
| **底层数据库扩展（`db`）** | 参数化查询与受限语句执行 | 仅在工作区显式开启高阶数据库扩展时可用；强制要求参数化绑定防止拼接错误，禁止修改或删除宿主内部系统迁移表与核心信封元数据表结构。 |
| **底层文件扩展（`files`）** | 指定子目录内文本/二进制读写与列举 | 访问范围严格限制在宿主预授权的工作区扩展子目录内；执行规范化路径解析（Canonicalization），拦截一切包含 `..` 的路径穿越、绝对系统盘符访问及指向沙箱外的符号链接（Symlink）。 |

---

## 四、关键决策

1. **默认收敛通用层，底层逃生舱按需受控开启**：第一版默认向工作台窗口完整开放第一层通用资源接口；第三层底层 `db` 与 `files` 接口定位为应对极端定制控件的逃生舱，默认收紧权限，按配置粒度显式授权，防止常规 Agent 开发误用底层接口破坏数据一致性。
2. **安全与一致性兜底绝不下放页面侧**：开放底层接口不代表放松宿主管控。路径边界检查、单次操作事务隔离、文件大小上限与受保护系统表拦截全部固化在宿主原生层执行，不信任来自 WebView 侧的原始路径或未校验参数。
3. **全局通信对象注入兼顾工程化与轻量脚本**：统一开启 `withGlobalTauri`，使前端既可通过标准 TypeScript SDK 模块化调用，又保留无构建工具条件下通过 `window.__TAURI__` 直接调测宿主接口的底层能力。

---

## 五、验收口径

1. **异常契约一致性**：模拟触发参数缺失、无权限命令调用、磁盘只读失败三类异常，前端接收到的响应均符合统一结构化错误契约，无未捕获崩溃或敏感宿主路径暴露。
2. **Capabilities 权限隔离**：在窗口权限配置中移除某项高阶命令授权后，前端调用该命令立即被 Tauri 权限层拦截拒绝，不影响其他已授权通用接口正常工作。
3. **路径沙箱防逃逸**：通过 `files` 扩展接口尝试传入相对回退路径、系统目录绝对路径及指向目录外的符号链接时，宿主 100% 识别拦截并返回越权错误码。
