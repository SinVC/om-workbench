# 前端运行时直接依赖

所有依赖由 Vite 本地打包，运行时不加载 CDN 资源。版本以根目录 package-lock.json 为准；完整许可证原文随 npm 包提供。FullCalendar 仅使用 MIT 标准版插件。

| @radix-ui/react-dialog | 1.3.1 | MIT |
| @tanstack/react-table | 9.3.1 | MIT |
| react | 19.3.1 | MIT |
| react-dom | 19.3.1 | MIT |
| recharts | 3.10.1 | MIT |
