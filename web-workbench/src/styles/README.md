# 视觉设计包

工作台的外观由两套完整、可切换的样式包组成，业务组件与逻辑不感知当前使用哪一套。

| 设计包 | 目录 | 风格 |
| :--- | :--- | :--- |
| **swiss**（默认） | `./swiss/` | 瑞士国际主义：暖石纸 / 黑曜石炭黑、赤陶主色、纯平面、2px 几何、无阴影无渐变 |
| **kairos**（备份） | `./kairos/` | 上一版编辑部风格：暖石墨、骨白、超大细体数字、发丝线与纸面质感 |

两套包都包含各自的 `tokens.css` 与 `global.css`；`index.css` 只负责指向当前生效的一套。

## 切换

```bash
npm run design:kairos   # 切回编辑部风格
npm run design:swiss    # 切回瑞士国际主义
npm run build           # 重新构建 dist
```

`design:*` 脚本只改写 `index.css` 中的一行 `@import`，不会改动组件、数据与宿主。两套设计的历史版本同时在 git 中保留，提交 `design/kairos` 标签对应上一版编辑器风格。

## 维护约定

- 新增或调整视觉时，优先改动当前设计包的 tokens；不要把某一套设计的颜色写进组件。
- 两套包的 DOM 与类名共用，新增类名需要在两套 `global.css` 中都能得到合理表现。
- 瑞士包内禁止 `box-shadow`、渐变与悬浮位移动画；切换前用仓库检查确认。
